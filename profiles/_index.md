# Profiles index

Reusable **content profiles**: pillars + audience + voice.  
Accounts point here; do not copy profile bodies into account files.

| id | path | voice | one_liner | accounts | product_ids | recommendation_scope |
|----|------|-------|-----------|----------|-------------|---------------------|
| default | profiles/default/ | `profiles/default/voice.md` | Replace this one-liner with the profile’s job | your-handle | none | none |

## Voice column

- Empty or `profile` → load `profiles/<id>/voice.md`
- Explicit path → load that file instead

`profiles/<id>/lanes.md` describes publishing lanes such as teaching, building,
reviewing and comparing. A lane is not a replacement for a pillar.
