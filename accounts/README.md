# accounts/

| File | Role |
|------|------|
| `_index.md` | **Source of truth** for handle → profile, platforms, voice, overrides path |
| `overrides/<handle>.md` | **Optional** — only when account-only deltas exist; path listed in `_index.overrides` |

Do **not** keep a full `accounts/<handle>.md` for every account.  
Pillars/audience bodies stay under `profiles/<id>/`.
