# Recommendations index

entries are provided.

| -- | ---- | ------ | -------- | -------- | ------- | --------------- | ------------ | ---- |

## Status values

| status | Meaning |
|--------|---------|
| `candidate` | Captured for possible research; not publishable |
| `researched` | Evidence and limits recorded |
| `active` | Available for Topics and reviews |
| `retired` | No longer maintained or relevant |

`profiles` is a comma-separated many-to-many association. Use `*` only when
the subject is intentionally shared across all profiles. `pillars` records
where the subject is relevant; it does not make the subject an owned product.
