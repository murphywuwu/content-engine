# Platform: Threads

**Scope:** How to *write* for Meta Threads — length, tone, conversation norms.  
**Not in this file:** Who you are, product story, pillars, voice, audience.  
**Pixels / canvas:** Optional; if images, follow EasySociable `PLATFORM_SPECS` for **threads** (often shared with IG **4:5 @ 1080×1350**).

Agent: before drafting any Threads post, read this file for craft.

---

## Defaults

- Language: English (unless user asks otherwise)
- Default unit: **1 conversational short post** (≤500 characters available — use only what you need)
- Assume calmer, Instagram-adjacent feed: **invitation > combat**
- Pack: **optional**. Prefer text (+ one image) unless the user wants a mini carousel
- Role for easysociable-builder: **secondary** surface — warm process / questions; not the main agency acquisition channel (X / LinkedIn lead)

## Length & shape

| Form | Guidance |
|------|----------|
| Single post | 1–5 short sentences. Room for one nuance line X might cut. End with a **real question** when you want replies. |
| Reply | Add substance or a precise follow-up. Same ban on empty praise as X. |
| Media | Images help; don’t rely on a 10-slide deck as the default Threads unit. |
| Cross-post from X | **Rewrite.** Do not paste X dunks unchanged. |

## Hooks (mechanics only)

A strong open usually:

- Shares a **process observation** (“We stopped letting the agent pick templates silently…”)
- Offers a **small, stealable rule**
- Asks an **answerable** ICP question

Avoid opening with maximum contrarian heat meant for X ratio.

## Craft rules

1. Tone: warmer, more human, less debate-club than X.
2. Optimize for **replies and positive conversation**, not quote-dunk chains.
3. Good fits: behind-the-scenes, experiment notes, “what’s your bottleneck?”, light system tips.
4. Bad fits as primary: hard category warfare, political newsjacking, long frameworks (send those to LinkedIn).
5. EasySociable: mention lightly as visual production layer when relevant — no install sermon.
6. One topic tag max if used; no hashtag walls.

## Anti-slop (Threads)

Do **not** default to:

- Raw paste of an X banger
- Corporate LinkedIn voice
- Engagement bait with no point
- Fake vulnerability / engagement-pod energy
- Treating Threads as the only growth channel for AI-native agencies

## Quality self-check

- [ ] Would this feel natural in a calm group chat, not a town-hall fight?
- [ ] If there’s a question, can a busy operator answer in one sentence?
- [ ] Rewritten for Threads — not an X clone?
- [ ] Media optional and not a tiny-type PDF dump?
- [ ] No invented metrics?

## Out of scope here

- Meta ads / Instagram cross-post mechanics  
- Full carousel systems → prefer `ig.md` / `linkedin.md` / `tiktok.md`  
- Other networks → sibling `platforms/*.md`
