# Platform: TikTok

**Scope:** How to *write* for TikTok — especially **Photo Mode / slideshow** craft.  
**Not in this file:** Who you are, product story, pillars, voice, audience.  
**Pixels / canvas:** EasySociable `PLATFORM_SPECS` — default **9:16 @ 1080×1920** for Photo Mode; keep text out of UI chrome safe zones.

Agent: before drafting any TikTok slideshow/post, read this file for craft.

---

## Defaults

- Language: English (unless user asks otherwise)
- Default unit for easysociable-builder: **photo slideshow (carousel)** competing in For You next to video
- Assume: if slide 1 fails, slides 2–N never exist
- Pack: **yes**; design for **completion / swipe-through**, not desktop reading

## Length & shape

| Form | Guidance |
|------|----------|
| Slideshow | **6–10 slides** sweet spot (platform allows more; completion pressure rises). One line per slide when possible. |
| Slide 1 | Hook only — open loop, specific pain, or numbered promise. Not a course title. |
| Middle | One tip / mistake / step each. Max ~15 words/slide; hook slide often ≤10 words, huge type. |
| Last | Explicit save/share CTA is OK on TikTok (more direct than LinkedIn). |
| On-video / talking head | Only if user asks; not the default for EasySociable PNG runs. |

## Hooks (mechanics only)

Slide 1 usually does one of:

- Specific cringe / cost (“You redesign the carousel every Wednesday”)
- Numbered open loop (“7 production leaks agencies ignore”)
- Sharp contrast / “stop doing X”

Avoid textbook titles: “Content Systems Explained”.

## Craft rules

1. Write for a **video-trained thumb**: bigger type, fewer words, higher contrast than IG if needed.
2. Each slide must **earn the next swipe**; cut any slide that only restates.
3. Prefer listicle / mistakes / stack / steps formats.
4. Tone: spoken, direct, slightly punchy — not LinkedIn deck voice.
5. Agency worldview is OK if compressed into swipeable bites; deep theory → X or LinkedIn instead.
6. EasySociable as quick proof of visual production — not a feature tour.
7. Same aspect every slide; default 9:16 unless user overrides.

## Anti-slop (TikTok)

Do **not** default to:

- Soft corporate captions on slide 1
- Dense paragraphs or LI-style frameworks with 40 words/slide
- “Follow for part 2” without delivering value in-post
- Watermarked or letterboxed 4:5 content that looks like a wrong-platform export
- Comment-gate playbooks as the primary CTA for this brand

## Quality self-check

- [ ] Slide 1 works as a For You interrupt?
- [ ] Would a stranger swipe to slide 3 without loving you already?
- [ ] Word count low; type large; chrome-safe?
- [ ] Completion-friendly length (not a 20-slide essay)?
- [ ] 9:16 (or user-agreed alt) consistent across pack?
- [ ] No invented metrics?
