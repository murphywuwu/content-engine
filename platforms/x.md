## Defaults

- Language: English (unless user asks otherwise)
- Default unit: **1 short post** (not a thread), unless user asks for a thread
- Assume timeline scroll: **first line** does most of the work
- Success for easysociable-builder: **qualified replies / DMs**, not raw impressions
- Pack: **optional**. Text-first; add carousel/images when showing the visual production layer

## Length & shape

| Form | Guidance |
|------|----------|
| Single post | Prefer **1–3 short sentences** or tight line breaks. Rarely fill the full character limit. |
| Thread | Only if user asks. Tweet 1 = hook only; each next tweet = one idea; end without a summary paragraph that restates everything. |
| Reply | Add information or a precise question. Avoid “Great point!” / empty agreement. |
| Media | Optional. If used, text should still stand alone if the image fails. Carousel images = proof of system, not the default body. |

## Hooks (mechanics only — not your brand story)

A strong first line usually does **one** of:

- Names a **concrete mistake** or false belief
- States a **sharp contrast** (X vs Y)
- Opens a **gap** the rest of the post closes
- Gives a **specific** observation (not “in today’s world…”)

Avoid first lines that only announce a topic list (“Here are 3 tips to…”).

## Craft rules

1. **One idea per post** (or per thread tweet).
2. Prefer concrete nouns and verbs over abstract “value / leverage / unlock”.
3. Cut filler and restatements. No closing that only summarizes what was already said.
4. Line breaks are for rhythm, not for fake drama on every word.
5. Questions: use when you want replies; make them answerable, not vague (“thoughts?”).
6. Links: prefer zero or one; if needed, put after the point lands — not as the whole post.
7. Optimize for **classifiable takes** and conversation — authority/signal, not soft lifestyle chatter (that’s closer to Threads).
8. EasySociable only when earned; frame as **visual production layer**, never as full content OS.

## Anti-slop (X)

Do **not** default to:

- “In a world where…” / “Here’s the thing:” / “Let’s dive in”
- “It’s not X, it’s Y” as empty cadence with no substance
- Engagement bait with no point (“Who’s still awake?” / “Like if you agree”)
- Wall of hashtags
- Corporate intern tone or fake guru certainty without a claim the user owns
- Comment-gate lead magnets (“Comment SLIDES”) as the primary CTA
- **RIP Canva** / “AI replaced your designer” as the main hook
- Empty praise replies when engaging others’ posts

## Quality self-check (before showing draft to user)

- [ ] First line works without the rest?
- [ ] Would a stranger understand the claim in one read?
- [ ] Any sentence pure filler? Delete it.
- [ ] Does this match **pillars.md** (topic allowed), not only “sounds like a tweet”?
- [ ] Would the right ICP reply “we have this problem” / ask how — or only react with emoji?
- [ ] No invented metrics, customers, or results?
- [ ] If media: still makes sense as text-only?
