# Platform: Instagram

**Scope:** How to *write* for Instagram — caption, carousel norms, job-of-format.  
**Not in this file:** Who you are, product story, pillars, voice, audience.  
**Pixels / canvas:** EasySociable `PLATFORM_SPECS` — feed carousel default **4:5 @ 1080×1350** (or `1:1` if user wants max compatibility).

Agent: platform id in this vault is often `ig` (also accept `instagram` → this file).

---

## Defaults

- Language: English (unless user asks otherwise)
- Default unit for easysociable-builder: **feed carousel** (save/depth job) — **not** Reels unless the user explicitly asks for Reels
- Assume thumb stop on **cover slide**; caption supports the cover, does not replace it
- Pack: **yes** for carousel runs

## Length & shape

| Form | Guidance |
|------|----------|
| Carousel | **7–9 slides** common; keep one aspect for all slides. One tip/step per slide. Big type; few words. |
| Caption | 1–3 short lines: hook + what they’ll get by swiping. Optional soft CTA (“Save for your next brand kit”). |
| Reels | Only if user asks. Different job: discovery/reach. Do not silently turn a carousel brief into a Reel script. |
| Single image | Rare for system topics; prefer carousel when teaching steps. |

## Hooks (mechanics only)

Cover slide should:

- Stop the scroll with a **bold, specific promise or mistake**
- Signal “worth saving” (checklist, steps, before/after), not “watch me talk”

Caption line 1 mirrors the cover; no LinkedIn-length essay above the fold.

## Craft rules

1. **Visual first.** If the slides don’t work with sound off and skim-reading, rewrite.
2. Optimize carousel for **saves** and return visits — reference content, not dunks.
3. One idea per slide; max clarity over clever wordplay.
4. Keep brand kit / template consistency visible (this is where EasySociable proof belongs).
5. CTA: save / share to a teammate / soft follow — not comment-gate lead magnets.
6. Hashtags: light or none; never a block of 30.
7. Do not paste X thread text onto slides.

## Anti-slop (Instagram)

Do **not** default to:

- Wall-of-text slides
- Engagement bait (“Comment SAVE”) as the whole strategy
- Faceless “viral in 60 seconds” energy as the brand voice
- Using Reels trends/audio as required for every post
- Treating IG as a dump of LinkedIn PDF screenshots with tiny type

## Quality self-check

- [ ] Cover stops a visual scroll without reading the caption?
- [ ] Would someone save this to reuse next week?
- [ ] Words per slide low enough for mobile?
- [ ] Same aspect across the deck?
- [ ] Job clear: save/authority (carousel) vs reach (Reel) — and format matches?
- [ ] No invented metrics; EasySociable only if earned?
